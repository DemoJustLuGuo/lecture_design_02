# 阶段四前端界面与联调记录

## 1. 阶段四范围

阶段四目标是把阶段三提供的 FastAPI 接口接入 React 前端，形成可演示的 Web 系统。

本阶段重点包括：

1. 完成前端路由和基础布局。
2. 完成监控总览页面。
3. 完成基站管理和基站详情页面。
4. 完成故障日志页面。
5. 完成故障地图页面。
6. 完成诊断建议页面。
7. 完成模型评估页面。
8. 完成移动预警页面。
9. 验证前后端接口联调结果。

```text

```

```text

```

当前前端通过 Vite 代理访问后端：

```text
/api -> http://localhost:8000
```

已对接的后端接口：

| 前端页面 | 后端接口 |
| --- | --- |
| 监控总览 | `GET /api/dashboard/summary`, `GET /api/faults` |

| 基站详情 | `GET /api/stations/{station_id}` |

| 模型评估 | `GET /api/model/evaluation` |
| 移动预警 | `GET /api/faults`, `GET /api/faults/{fault_id}` |

## 6. 当前可演示故事线

阶段四当前可按以下顺序进行答辩演示：

1. 打开监控总览，展示基站数、当前告警数、严重故障数和模型准确率。
2. 进入故障日志，筛选或查看故障类型、严重程度和处理状态。
3. 进入故障地图，展示故障空间分布和基站位置。
4. 从故障样本进入诊断建议，展示根因分析和排障建议。
5. 进入模型评估，展示准确率、召回率、F1、混淆矩阵、定位误差和检测耗时。
6. 进入移动预警，展示面向运维人员的严重故障快速处理视图。

推荐演示故障样本：

```text
TS_anomalous__synthetic__Zone_C__Twitch_00016
```

该样本当前可正常打开诊断建议页面。
